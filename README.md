# 🦠 COVID-19 Data Analysis | SQL • Python • Power BI

An end-to-end **Data Analytics project** analyzing global and India-specific COVID-19 trends using **Python, SQL, MySQL, and Power BI**.

The project focuses on data cleaning, exploratory analysis, SQL-based business questions, DAX measures, data modeling, and interactive dashboard development.

---

## 📌 Project Overview

COVID-19 generated a large amount of time-series data containing information about cases, deaths, population, vaccination, and other country-level indicators.

In this project, I transformed raw COVID-19 data into meaningful analytical insights using:

- 🐍 Python for data cleaning and preparation
- 🗄️ MySQL for data analysis
- 📊 Power BI for interactive visualization
- ⚡ DAX for analytical measures
- 📈 Time-series and comparative analysis

The final Power BI dashboard contains two pages:

1. **Global COVID-19 Overview**
2. **India COVID-19 Analysis**

---

# 🎯 Business Objectives

The main objectives of this project were to:

- Analyze the global impact of COVID-19
- Track COVID-19 cases and deaths over time
- Identify countries with the highest total cases
- Identify countries with the highest total deaths
- Compare COVID-19 impact across continents
- Analyze vaccination coverage
- Understand monthly COVID-19 trends
- Calculate India's COVID-19 death rate
- Compare cases and deaths in India
- Build an interactive dashboard for decision-making
